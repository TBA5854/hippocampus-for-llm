# Experiments — stateful transformer via an in-block memory

## Objective

A memory block inside the stack, **read at layer 1, write at the last block before the head**, that
makes the model stateful: it answers from its own store with nothing in the prompt. No RAG, no injected
context. Compressed, episode-integral, persistent.

**Done means:** cross-segment recall at **>= 8 facts**, facts entirely out of context, store saved to
disk and reloaded, with matched controls (store disabled, scrambled store) at chance.

## Protocol

Every round `rN`: **ideate -> hypothesise -> experiment -> diagnose -> write up -> commit**, then open
`rN+1`. A negative result is written up and committed, never re-run until it looks better.

```
rN/HYPOTHESIS.md   claim, prediction, what falsifies it
rN/run.sh          exact commands, runnable
rN/logs/           raw stdout, synced from the box
rN/results/        --out JSON
rN/RESULTS.md      numbers, verdict, diagnosis, next question
```

`STATE.md` is the resume point. A 30-minute in-session cron re-reads it after a network blip.

Guardrails: controls at matched settings every round; report peak **and** final recall (`mq_on`
peaked at 67.2% and ended at 26.7%); scale content with store size so no axis is fake; the
100 / 4.4 / 4.2 / 3.1 separation must survive every change or its cost is reported.
